# Batocera TATE Controls Installer

A GitHub Pages-ready web tool for installing automatic clockwise RetroArch control remaps for vertical arcade games on Batocera/KNULLI devices.

The app is intentionally plain:

- Static HTML, CSS, and JavaScript only.
- No build step.
- No npm dependencies.
- No external scripts or CDNs.
- No file uploads. Browser folder access stays local to the user's machine.

## Recommended Sharing Setup

1. Create a GitHub repository.
2. Copy this folder's files into the repo root.
3. In GitHub, open **Settings > Pages**.
4. Publish from the repo's main branch.
5. Share the GitHub Pages URL.

The folder can also be served locally for testing:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in Chrome or Edge.

## Browser Support

The installer uses the File System Access API, so folder writing currently works best in desktop Chrome or Edge over HTTPS. GitHub Pages is HTTPS, so it is a good hosting target.

Firefox and Safari may not expose the folder-writing API needed for this tool.

## What It Installs

The tool asks the user to select the root of their Batocera SHARE drive. It then previews all planned changes before writing anything.

It writes:

- `system/scripts/tate-rotate-controls.sh`
- A marked block inside `system/custom.sh`
- Optional RetroArch game remaps under `system/configs/retroarch/config/remaps/`

`custom.sh` is deliberately named that way because Batocera/KNULLI calls `/userdata/system/custom.sh` during boot. The descriptive script is `tate-rotate-controls.sh`; `custom.sh` is just the conventional boot hook.

## Remap Behavior

The generated remaps rotate player 1 controls clockwise for TATE mode:

- D-pad directions
- Left-stick-as-D-pad mode
- ABXY face buttons

The tool uses arcade metadata files already present on the SHARE drive to detect vertical games:

- `bios/mame2003-plus/mame2003-plus.xml.gz`
- `bios/mame2010/mame2010.xml.gz`
- `bios/fbneo/FinalBurn Neo (ClrMame Pro XML, Arcade only).dat`

Existing hand-made remap files are preserved unless they already contain the installer marker:

```text
Generated by tate-rotate-controls.sh
```

## Backups

When replacing an existing script file, the installer writes a timestamped backup next to it, such as:

```text
custom.sh.tate-backup-20260513-184500
```

## Device Notes

The boot hook runs this command on startup:

```bash
/bin/bash /userdata/system/scripts/tate-rotate-controls.sh --refresh-all
```

Using `/bin/bash` matters for SD cards formatted as exFAT because executable permission bits may not be available.

Batocera's normal launcher script hook is also supported by `tate-rotate-controls.sh` when executable script hooks are available.
