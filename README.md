# Batocera TATE Controls Installer

[Launch Tool](https://jamesiv4.github.io/Batocera-TATE-Controls-Remap-Generator/)

A web tool for installing automatic clockwise RetroArch control remaps for vertical arcade games on Batocera/KNULLI devices.

The tool can optionally generate remap files ahead of time for your current TATE games, and it also installs a boot script that creates remaps on-device for any newly added TATE games.

The code is intentionally transparent and plain:

- Static HTML, CSS, and JavaScript only.
- No external scripts or CDNs.
- No file uploads. Browser folder access stays local to the user's machine.

## What It Installs

The tool asks the user to select the root of their Batocera SHARE drive. It then previews all planned changes before writing anything.

It writes:

- `system/scripts/tate-rotate-controls.sh`
- A marked block inside `system/custom.sh`
- Optional RetroArch game remaps under `system/configs/retroarch/config/remaps/`

The `custom.sh` boot hook lets the remap script run automatically when the device starts.

## Remap Behavior

The generated remaps rotate player 1 controls clockwise for TATE mode:

- D-pad directions
- Left-stick-as-D-pad mode
- ABXY face buttons

The tool uses arcade metadata files already present on the SHARE drive to detect vertical games:

- `bios/mame2003-plus/mame2003-plus.xml.gz`
- `bios/mame2010/mame2010.xml.gz`
- `bios/fbneo/FinalBurn Neo (ClrMame Pro XML, Arcade only).dat`

Existing hand-made remap files are preserved unless they already contain the installer marker:

```text
Generated by tate-rotate-controls.sh
```

## Web Installer Creates Backups

When replacing an existing `custom.sh` script file, the web installer writes a timestamped backup next to it, such as:

```text
custom.sh.tate-backup-20260513-184500
```

## How the Boot Hook Script Works

The boot hook runs this command on startup:

```bash
/bin/bash /userdata/system/scripts/tate-rotate-controls.sh --refresh-all
```

The boot refresh scans for vertical arcade games and creates missing remaps or updates generated remaps whose contents have changed.

## Browser Support

The installer uses the File System Access API, so folder writing currently works best in desktop Chrome or Edge over HTTPS.

Firefox and Safari may not expose the folder-writing API needed for this tool.
